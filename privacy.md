# Privacy Policy - Nano Banana Pro Plugin

**Last Updated:** 2026-02-07

## Overview

This privacy policy describes how the Gemini Draw plugin handles user data when integrated with Dify applications.

## Data Collection

### What We Collect

The Gemini Draw plugin processes the following data:

1. **User Inputs**
   - Text prompts for image generation
   - Images uploaded for transformation
   - Configuration parameters (aspect ratio, quality settings)

2. **API Credentials**
   - Gemini API keys (stored securely in Dify's credential system)

### What We Don't Collect

- Personal identifiable information (PII)
- User metadata or analytics
- Usage statistics beyond what Dify platform provides

## Data Usage

### How We Use Your Data

1. **Image Generation**: Your text prompts and images are sent to Google Gemini API for processing
2. **API Authentication**: Your API key is used solely to authenticate requests to Gemini API
3. **Response Delivery**: Generated images are returned to your Dify workflow

### Third-Party Services

This plugin integrates with:

- **Google Gemini API** - For AI image generation and transformation
  - Subject to [Google's Terms of Service](https://policies.google.com/terms)
  - Subject to [Google's Privacy Policy](https://policies.google.com/privacy)

## Data Storage

- **No Persistent Storage**: This plugin does not store any user data permanently
- **Temporary Processing**: Images and prompts are processed in-memory only
- **Credentials**: API keys are stored securely by Dify's credential management system

## Data Sharing

We do not share, sell, or distribute your data to any third parties except:

- **Google Gemini API** - Required for plugin functionality
- As required by law or legal process

## User Rights

You have the right to:

- Use this plugin without providing personal information
- Remove the plugin and associated credentials at any time
- Request information about how your data is processed

## Security

- All API communications use HTTPS encryption
- API keys are never logged or exposed in responses
- No data retention beyond active processing

## Compliance

This plugin follows:

- Dify Platform's privacy requirements
- Google Gemini API's usage policies
- General data protection principles

## Changes to This Policy

We may update this privacy policy as needed. Significant changes will be reflected in the plugin's version updates.
